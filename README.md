# Книга

Рукопись на русском (`ru/`) и английском (`en/`), правила и инструменты.

| Файл | Что это |
|---|---|
| `STYLE.md` | Свод правил: стиль, анти-ИИ, ориентир бестселлеров, оформление, перевод |
| `BIBLE.md` | Персонажи, хронология, ружья, глоссарий перевода |
| `ru/NN-*.md` | Главы на русском |
| `en/NN-*.md` | Главы на английском |
| `tools/check.py` | Проверка стиля: `python3 tools/check.py ru/01-*.md` |
| `tools/build.py` | Сборка docx/epub/fb2 в `build/`: `python3 tools/build.py` |
| `tools/gdocs.py`, `tools/gdocs.json` | Зеркало в Google Docs (ID документов в `gdocs.json`) |
| `drafts/` | Исходные наброски автора, как они были до переработки |

Нужны pandoc ≥ 3 и `pip install python-docx`.

## Google Docs

Читать удобнее в Google Docs. Там лежат две копии, которые всегда повторяют последнюю версию из репозитория:

- RU: «Лишний человек» (документ автора)
- EN: «Лишний человек (EN)»

Правда хранится в git: здесь история и откат на любую версию. Документ в Google Docs при каждом обновлении переписывается целиком.

Перед каждым обновлением я читаю документы. Комментарии разбираю и отвечаю на них в чате. Если автор правил текст прямо в документе, сначала переношу эти правки в `ru/` или `en/`, иначе они потеряются.
